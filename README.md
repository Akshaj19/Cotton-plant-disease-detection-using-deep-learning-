# 🌿 Cotton Leaf Disease Detection using Hybrid Deep Learning

## 📌 Overview
This project presents a hybrid deep learning-based system for detecting diseases in cotton leaves. It combines pretrained models **ResNet50** and **DenseNet121** to improve classification accuracy and provide reliable predictions.

The system allows users to upload cotton leaf images and receive real-time disease detection results through a simple web interface.

---

## 🚀 Features
- Detects cotton leaf diseases from images  
- Hybrid deep learning model (ResNet50 + DenseNet121)  
- High accuracy (~98%)  
- Real-time prediction using Streamlit  
- User-friendly interface  
- Supports early disease detection  

---

## 🧠 Technologies Used
- Python  
- TensorFlow / Keras  
- OpenCV  
- NumPy, Pandas  
- Streamlit  

---

## 📸 Usage
1. Open the Streamlit app in your browser  
2. Upload a cotton leaf image  
3. Click on **Predict**  
4. View the result  

---

## 📊 Model Details
- **Base Models:** ResNet50, DenseNet121  
- **Approach:** Feature extraction + hybrid fusion  
- **Classifier:** Fully connected layer  

**Output Classes:**
- Healthy  
- Bacterial Blight  
- Leaf Curl Virus  
- Fusarium Wilt  

---

## 📈 Results
- Accuracy: ~98%  
- High precision, recall, and F1-score  
- Stable performance
