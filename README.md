🌿 Cotton Leaf Disease Detection using Hybrid Deep Learning
📌 Overview

This project presents a hybrid deep learning-based system for detecting diseases in cotton leaves. It combines pretrained models ResNet50 and DenseNet121 to improve classification accuracy and provide reliable predictions.

The system allows users to upload cotton leaf images and get real-time disease detection results through a simple web interface.

🚀 Features
Detects cotton leaf diseases from images
Uses hybrid deep learning (ResNet50 + DenseNet121)
High accuracy (~98%)
Real-time prediction using Streamlit
User-friendly interface
Supports early disease detection for better crop management


🧠 Technologies Used
Python
TensorFlow / Keras
OpenCV
NumPy, Pandas
Streamlit


📸 Usage
Open the Streamlit app in your browser
Upload a cotton leaf image
Click on predict
View the disease classification result

📊 Model Details
Base Models: ResNet50, DenseNet121
Approach: Feature extraction + hybrid fusion
Classifier: Fully connected layer
Output Classes:
Healthy
Bacterial Blight
Leaf Curl Virus
Fusarium Wilt

📈 Results
Accuracy: ~98%
High precision, recall, and F1-score
Stable and reliable predictions
